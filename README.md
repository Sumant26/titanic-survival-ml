# 🚢 Titanic Survival Predictor

Predict which passengers survived the Titanic using classification models.

**Skills:** classification · logistic regression · random forest · gradient boosting · confusion matrix · precision/recall · feature engineering · Kaggle submission

**Time:** one weekend · **Level:** beginner (do the house price project first)

## Run it
1. Open [Google Colab](https://colab.research.google.com) → **File → Upload notebook** → `titanic_survival.ipynb`.
2. Run the cells top to bottom (**Shift + Enter**). The data downloads automatically.
3. For the Kaggle leaderboard, follow section 13 in the notebook.

## Expected results
| Model | Accuracy |
|---|---|
| Predict "died" for everyone | ~62% |
| Logistic regression | ~80–83% |
| Tuned tree ensemble | ~80–84% |
| Kaggle leaderboard (first submission) | ~77–79% |

Data: [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic).
